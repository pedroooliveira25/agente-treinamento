# slides/

Coloque aqui o material original.

1. Baixe o PDF: https://drive.google.com/file/d/1JvyxlJ34qRERnUP1KxevwuW2BaAZ-tfX/view
2. Salve como `slides/slides.pdf` (não versionar conteúdo sensível, só o treinamento)
3. Extraia o texto para `slides/conteudo.txt` (ou vários `01-*.txt`, `02-*.txt`...)
4. Rode `node scripts/unificar.js`

O download direto pelo terminal pode falhar se o link exigir login — nesse caso baixe pelo browser.
